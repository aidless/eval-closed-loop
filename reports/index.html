分数可复现性的实测下界（A-cot / n=300 × 3 次）

同一配置（同一 300 题、同一顺序、temperature=0.0、 seed=42）完整重跑 3 次， 准确率分别为 0.6833, 0.6700, 0.6700； 两两最大差 1.33 pp， 分数层面最大跨度 1.33 pp。 1 题 = 0.33 pp，分数的抖动是“几道题”的量级。 三次并非均匀抖动：var2=var3 的逐题判分完全一致，1.33 pp 的跨度全部来自 var1 与其余 run 的差异，且这组翻转题在不同对比里完全相同。

逐题：300 题里 10 题（3.33%） 三次不完全一致，其余 198 题全对、 92 题全错。翻转题中 没有出现相对误差 ≤1% 的数值近失（抽不出数字的 0 题），翻转是整条推理链换支，而不是末尾算术差一两个单位； 两次输出的首个差异点中位落在第 10% 字符位置，分叉出现得较早，不只是尾部措辞差异。桶内翻转率从 steps_3_4 的 2.0% 到 steps_5_plus 的 5.4%。

门禁 Δ 阈值：由逐题翻转估计同配置两次跑的 Δ 标准差 sd=0.86 pp（n=300 实测）； 要 95% 不被噪声触发，|Δ| 阈值至少 1.96σ=1.68 pp， 保守取 3σ=2.58 pp （实测最大 |Δ| 为 1.33 pp， 取二者较大值 → 建议下限 2.58 pp， 约 7.73 道题）。 当前 max_regression=5%： 在 n=300 实测下，5pp 阈值相当于 3σ 的 1.9×；按推算 n=1,319 时约 4.1×，n=60 时约 0.9×；所以本轮的 BLOCK（Δ=-0.603）不可能是噪声触发。按 q/n 缩放到其他样本量：n=60 → 3σ≈5.77 pp；n=300 → 3σ≈2.58 pp；n=1319 → 3σ≈1.23 pp（推算，未验证）。注意：n=60 的 3σ 推算值 5.77 pp 已经超过当前 5pp 阈值，噪声本身就能跨过线——n=60 的门禁判决只能当方向性信号，不能单独作为放行/阻断依据。

局限与未验证项

  • 本报告为 N=1319 档：n=60 / n=300 / 全量 1,319 是三份独立抽样，不能混算；区间与 n 必须一起读。

  • 类别是按金标解题行数派生的难度桶（1-2 / 3-4 / 5+ 行），不是 GSM8K 官方分类。
  • 样本量推算与 CPU 成本外推均标未验证；实际跑到的 n 才是结论依据。
  • 两个主模型均 ≤1.5B，没有 API 强模型对比；judge 只看最终答案，不评价推理过程。
  • 成本为同机实测（GPU 另有训练进程并发），不作跨机器基准；CPU 只做 n=100 抽样，不外推。
  • 三个 run 均串行独立执行：并发会让 0.5b 被挤到 CPU（单题 ~20s），B-cot 早期 6 条已作废重跑。
  • 分数可复现性探针是同一 n=300 子集额外完整跑 3 次（独立进程、间隔 >=3 min），不与主表 n=300 混算；主表数字未改写。
